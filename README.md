# Kademis

Plataforma multi-instituição de gestão educacional.

## Estado atual

O Kademis está em fase de fundação do produto. Este repositório é a referência oficial para documentação, decisões, design, arquitetura e, posteriormente, implementação.

Neste momento:

- o produto está sendo redefinido a partir de um novo baseline;
- o projeto legado **SGSA - Old** é apenas referência histórica;
- a identidade visual está em definição controlada;
- o **Master Development Playbook v0.1** está registrado como **PROPOSTO**, aguardando revisão para se tornar baseline metodológico;
- a arquitetura técnica e a stack ainda não foram escolhidas;
- nenhuma estrutura de frontend, backend, banco ou infraestrutura foi criada.
