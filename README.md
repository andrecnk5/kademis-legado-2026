# Kademis

Plataforma multi-instituição de gestão educacional.

## Estado atual

O Kademis está em fase de fundação do produto. Este repositório é a referência oficial para documentação, decisões, design, arquitetura e, posteriormente, implementação.

Neste momento:

- o produto está sendo redefinido a partir de um novo baseline;
- o projeto legado **SGSA - Old** é apenas referência histórica;
- a identidade visual está em definição controlada;
- o **Master Development Playbook v1.0** está **APROVADO** como baseline metodológico;
- a **Fase 0 — Governança do Projeto** está **CONCLUÍDA — Gate 0 APROVADO**;
- a **Fase 1 — Visão, Problema e Estratégia** está **CONCLUÍDA — Gate 1 APROVADO**;
- o **Product Charter v0.1** está integrado à `main` como **APROVADO — BASELINE ESTRATÉGICO DA FASE 1**;
- a **Fase 2 — Negócio e Stakeholders** está **CONCLUÍDA EM CONTEÚDO — Gate 2 APROVADO**, aguardando integração do Stakeholders v0.1 na `main`;
- a **Fase 3 — Descoberta do Domínio** ainda não foi iniciada e dependerá de novo chat, reconstrução do estado oficial e autorização explícita;
- a arquitetura técnica e a stack ainda não foram escolhidas;
- nenhuma estrutura de frontend, backend, banco ou infraestrutura foi criada.
