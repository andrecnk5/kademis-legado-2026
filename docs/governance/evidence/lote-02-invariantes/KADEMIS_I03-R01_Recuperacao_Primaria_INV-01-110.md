# 1. Objetivo e regra probatória

A atividade auditou individualmente os 110 identificadores solicitados, procurando:

1. enunciado literal final;
2. mensagem original de proposição e autoria;
3. manifestação humana de validação/aprovação;
4. refinamentos/versões;
5. localização temporal/contextual;
6. situação documental;
7. situação decisória;
8. lacunas/divergências.

Foi aplicada a seguinte regra:

- uma **consolidação posterior**, memória, relatório RDOC ou handoff pode orientar a busca;
- ela **não substitui** uma mensagem primária ausente;
- nenhum enunciado ausente foi reconstruído por inferência;
- nenhum status foi elevado para APROVADO/VALIDADO sem distinguir a suficiência documental dessa afirmação.

## 1.1 Limitação técnica relevante

O ambiente de recuperação não reexpõe de maneira uniforme todos os turnos antigos do chat. Isso produziu três classes reais de evidência:

- **COMPROVADO** — mensagem primária suficiente recuperada para o enunciado e a decisão;
- **PARCIALMENTE COMPROVADO** — algum elemento material da cadeia primária ficou indisponível;
- **NÃO COMPROVADO** — a fonte primária disponível não foi suficiente para o identificador.

Essa limitação não foi preenchida por paráfrase.
