## Entrada e execução

1. Avaliador autorizado registra identidade, data, commit e acesso efetivo. Começa pelo README e índice de continuidade.
2. Recebe somente o repositório no commit e localizadores de custódia; não recebe respostas do executor original nem esta conversa.
3. Para cada pergunta abaixo, responde com caminho, versão/status, ato/limite e evidência suficiente, ou declara impedimento concreto.
4. Testa acesso às fontes externas que considerar materiais. Um ID sem procedimento/acesso efetivo não basta para declarar recuperabilidade futura.
5. Registra SUFICIENTE / INSUFICIENTE / NÃO AVALIADO por critério. Não reabre limitações antigas como novas pendências; referencia o controle existente e explica impacto no uso.
